# Avg

One spec for the floor average of two `u64`s, and two implementations proved equal to it:
the Rust source (through Aeneas) and the RISC-V machine code rustc compiles it to.

## Layout

```
spec/AvgSpec.lean          avgSpec + bridge theorem   (trusted; core Lean only)

fast/                      avgFast, avgNaive + proofs (core Lean only)
  AvgFast/Impl.lean        avgFast, avgNaive
  AvgFast/Proofs.lean      avgFast_eq_spec, avgFast_toNat, avgFast_noOverflow
  AvgFast/Naive.lean       avgNaive_ne_spec
  AvgFastTest/             `lake test`: #guard_msgs on bv_decide's counterexample

aeneas/                    Lean v4.31 + Aeneas
  AvgAeneas/Extracted/     Rust.avg, generated by Aeneas from rust/  (never edit)
  AvgAeneas/Proofs.lean    rust_avg_correct: Rust.avg never panics and equals avgSpec

riscv/                     Lean v4.33 + riscv-zkvm
  AvgRiscv/Program.lean    avgProgram: rustc's RV64IM output for `avg`
  AvgRiscv/Proofs.lean     avgProgram_correct: 5 steps, returns to ra, a0 = avgSpec a b

rust/                      the Rust crate
scripts/check-riscv-asm.py checks rustc's disassembly == avgProgram
```

Both proof packages reuse `fast/`: the Rust and the RISC-V code both compute `avgFast`, so
each finishes with `avgFast_eq_spec`. `aeneas/` and `riscv/` are separate Lake packages
because Aeneas pins Lean v4.31.0 and riscv-zkvm pins v4.33.0. `spec/` and `fast/` import
nothing beyond core Lean, so both sides compile the same `avgSpec` and `avgFast`.

## Checking

```bash
(cd aeneas && lake build)               # Aeneas side
(cd fast && lake build && lake test)    # avgFast / avgNaive
(cd riscv && lake build)                # RISC-V side
scripts/check-riscv-asm.py              # rustc 1.94.0 output == avgProgram
```
